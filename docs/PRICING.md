# Pricing

ROAR is private Windows dictation you own.

ROAR Core is free.
ROAR Pro is $19 once.
ROAR Developer is $29 once.
ROAR Supporter is $49 once.

No subscription.
No account required.
No cloud transcription.
No telemetry.

## What each edition is for

- **ROAR Core (Free)** — private, local, offline dictation. Push-to-talk,
  hands-free, streaming preview, multilingual, history, all privacy controls,
  basic vocabulary, scratch-that.
- **ROAR Pro ($19 once)** — smarter local dictation: smart formatting, snippet
  packs, vocabulary suggestions, history filters/tags, advanced cleanup,
  settings import/export, advanced milestones.
- **ROAR Developer ($29 once)** — a code-aware voice layer: code mode, symbol
  dictation, app profiles, per-app language, project vocabulary, file tagging,
  developer snippet packs.
- **ROAR Supporter ($49 once)** — everything in ROAR Developer, and it supports
  continued independent development. There are no exclusive Supporter features.

Buy once, use forever. Your purchase includes all v1.x updates. Optional paid
major upgrades may happen later, but the version you purchased keeps working.

Core dictation, offline use, privacy controls, and history/audio deletion are
free in every edition and always will be.

Prices live in exactly one place — `PRICING` in `commercial_config.py`. This
document, the in-app upgrade copy, and the website all follow it, and tests fail
if any of them drift.
