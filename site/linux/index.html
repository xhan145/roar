Linux Preview

Install and verify the Linux Preview

ROAR Linux is an x86_64 AppImage Preview. Availability appears on the download page only after a verified release manifest includes a matching package and checksum.

Install

chmod +x ROAR-Linux-<version>-x86_64.AppImage
sha256sum ROAR-Linux-<version>-x86_64.AppImage
./ROAR-Linux-<version>-x86_64.AppImage

Compare the printed SHA-256 with the full checksum on the verified download card before launching. The AppImage launches directly; it does not need a package manager installation.

What has been automatically checked

The package workflow runs an Ubuntu 24.04 automated package smoke check for the x86_64 AppImage, including the frozen application and extracted AppImage launch path.

Known limitations

Use X11 for this Preview. The supported path is X11. Wayland is not supported in this Preview. No Linux GPU support claim is made.

Manual real-device gates still required

  • Microphone capture on your actual device.
  • Global hotkey registration and reliable cross-application text injection on X11.
  • Settings, permissions, suspend/resume, and a full dictation session on the target desktop.
